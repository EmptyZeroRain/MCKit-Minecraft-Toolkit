# 部署形态与会话方案

> 对应 `gj.md` §3.4 / §17 阶段一「明确单实例/多实例部署约束和会话方案」。
> 配置项以 `backend/internal/config/config.go` 与 `.env.example` 为准。

## 1. 部署形态约束

| 形态 | 会话存储 | 约束 |
| --- | --- | --- |
| 单实例（默认） | `SESSION_STORE=memory` | 进程重启（含滚动升级、容器重建）后**全部会话失效**，用户需重新登录；不支持横向扩容。 |
| 多实例 | `SESSION_STORE=postgres` | 会话写入 `sessions` 表，所有实例共享；创建 / 续期 / 撤销即时一致；进程重启不丢会话。 |

生产环境若计划运行 **多于一个 API 实例**，必须：

1. 设置 `SESSION_STORE=postgres`；
2. 确认所有实例连接**同一个** PostgreSQL；
3. 完成迁移（`0030_sessions.sql` 创建 `sessions` 表）；
4. 验证「A 实例登录 → B 实例可识别」「在 B 实例撤销 → A 实例立即失效」。

未满足上述条件时，只能按单实例部署，并在运维记录中明确「进程重启会使全部用户离线」这一已知行为。

## 2. 会话参数

| 环境变量 | 默认 | 说明 |
| --- | --- | --- |
| `SESSION_STORE` | `memory` | `memory` / `postgres`，非法值启动即失败。 |
| `SESSION_TTL_HOURS` | `72` | **绝对有效期**，自会话创建起计算，续期不能越过。 |
| `SESSION_IDLE_MINUTES` | `0` | **空闲超时**，自最近一次活动起计算；`0` 表示不启用；超过 `SESSION_TTL_HOURS` 时按绝对值收敛。 |
| `SESSION_SECURE_COOKIE` | `false` | 生产（HTTPS）必须设为 `true`。 |
| `SESSION_COOKIE_NAME` | `mc_session` | 管理员与普通用户共用同一个会话 Cookie。 |
| `SESSION_SECRET` | 必填 | 至少 16 字符的强随机值；缺失或过短拒绝启动。 |

Cookie 属性固定为 `HttpOnly` + `SameSite=Lax`（`Secure` 由配置控制），路径 `/`。

## 2.1 双因子认证（MFA）相关变量

| 环境变量 | 默认 | 说明 |
| --- | --- | --- |
| `MFA_ENCRYPTION_KEY` | 空 | AES-256-GCM 密钥，16/24/32 字节的 base64 或 hex；格式非法启动即失败。留空表示不部署 MFA，此时**已绑定 MFA 的账号会被拒绝登录**（不降级为单因子），需先执行「重置 MFA」。 |
| `MFA_ISSUER` | `MC 工具站` | 认证器 App 中展示的服务名。 |

多实例部署时所有实例必须使用**同一把** `MFA_ENCRYPTION_KEY`，否则各自无法解密对方的 secret。
更换密钥会让历史绑定全部失效，操作步骤见 `docs/管理员MFA.md`。

## 3. 安全失败语义

共享会话存储不可用时（数据库连接失败、超时等）：

- `RequireAuth` 返回 **503 `SERVICE_UNAVAILABLE`**，而不是 401，也不是放行；
- 绝不降级为「跳过认证」；
- 恢复后无需重启实例即可继续服务。

实现位置：`backend/internal/http/middleware/auth.go`（`ErrSessionStoreUnavailable` 分支）。

## 4. 撤销机制

| 触发场景 | 行为 |
| --- | --- |
| 用户登出 | 删除当前会话 |
| 修改密码（自助） | 删除该账号全部会话，强制重新登录 |
| 管理员重置密码 | 删除该账号全部会话 + 置 `must_change_password` |
| 改角色 / 停用 / 删除账号 | 删除该账号全部会话（共享存储另有外键级联兜底） |
| 用户自助「退出其它设备」 | `POST /api/v1/admin/auth/sessions/revoke`（`scope=others/all`） |

会话 ID 是 Cookie 中的 bearer 凭据，接口只返回其 **SHA-256 前 12 位指纹**用于辨认，不回显原文。

## 5. 过期清理

进程内每小时执行一次 `PurgeExpired`：

- 内存存储：清理 map 中的过期项；
- 共享存储：`DELETE FROM sessions WHERE expires_at <= now() [OR last_seen_at <= now() - idle]`。

另外读取路径会对命中但已过期的会话做惰性删除。
